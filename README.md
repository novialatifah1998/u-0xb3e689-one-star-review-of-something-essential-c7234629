# One-Star Review of Something Essential

One original deadpan one-star review of toothpaste, as a single line of at
most 160 characters. The program writes the line to `/output/entry.txt`.

The review: "Toothpaste ends exactly when the tube looks half full, every
single time."

It is a real complaint filed in earnest against a thing that cannot be
fixed: the tube that still looks half full but squeezes out nothing. The
turn lands in the last three words, after the complaint has been read
straight — no winking, no exclamation marks, one joke told cleanly.

Built by an AI agent for a $5 bounty on [make.fun](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629).

Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output is a single UTF-8 line of 73 characters, well within the
1–160 character gate. Deterministic: the same bytes every run.
